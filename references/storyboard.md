# Сюжет сцены: как выбрать и разложить на шаги

## Когда сцена нужна

- Новая фича, которую не видно на экране без действия: поиск по новому полю, выбор из
  справочника, жест, горячее действие в меню.
- Изменилось место или способ привычного действия — пользователь ищет по-старому.

Не нужна, если фичу видно сразу (новая кнопка с понятной подписью) или если хватает одной
строки текста. Сцена дороже текста для внимания — тратьте её на то, что текстом не объяснить.

## Сюжет — одна фраза

Сформулируйте, что пользователь увидит в конце: «получатель выбран по никнейму». Это
финальный кадр. Всё, что к нему не ведёт, — лишнее.

Раскладка идёт **от конца к началу**: результат → последнее действие перед ним → … →
исходный экран. Обычно выходит 2–4 шага. Больше пяти — это две фичи.

## Шаги

| Шаг | Когда | Пример |
|---|---|---|
| `click(target, apply)` | пользователь нажимает | открыть справочник, отметить строку, нажать ОК |
| `type(target, text, apply)` | вводит короткий запрос | «asanov» в поиске |
| `point(target)` | что-то раскрывается по наведению | подсказка у значка, свёрнутое меню |
| `react(apply)` | интерфейс отвечает сам | пришёл ответ, появилась отметка «Отправлено» |

Правила раскладки:

- **Состояние сцены — только то, что меняется на экране.** Не моделируйте бизнес-логику:
  `{ modal, query, picked, chip }` достаточно.
- **Реакция на ввод — в `apply` того же шага.** Список фильтруется, пока идёт печать:
  разметка сцены читает `query` и сама решает, какие строки показать.
- **Цель — то место, куда нажал бы человек**: иконка книжки, а не всё поле; чекбокс строки,
  а не строка. `SceneTarget` оборачивает ровно цель.
- **Исходный экран — узнаваемый кусок настоящего.** Два-три поля из той формы, где фича живёт,
  с теми же подписями. Не весь экран — он не поместится и не прочитается.
- **Данные — демонстрационные**, но правдоподобные: имя, никнейм, название документа.
- **Строка списка — `SceneAppear`.** Тогда при нажатии на цель внутри неё строка сама
  подсветится, как строка `Table` в ДС, и подрастёт. Постоянный фон у отмеченной строки
  не рисуйте: в ДС его нет, отметку показывает сама галочка.

## Текст подсказки

- Заголовок — что это за фича, глаголом действия: «Найдите получателя по DG Name».
- Текст — зачем: чем это лучше старого способа. Одно-два предложения.
- Не пересказывайте сцену словами («нажмите на книжку, затем…») — это она показывает сама.
- Точки в конце нет. Прогнать через `sasha`.

## Анти-паттерны

- **Подбирать скорость «на глаз».** Кажется медленно — значит, в сцене лишний шаг, а не
  медленный такт.
- **Две фичи в одной сцене** («а ещё можно отсортировать»). Две подсказки.
- **Рисованный мокап** вместо компонентов. Разъедется с интерфейсом при первой же правке ДС.
- **Подсветка на каждом шаге.** Акцент один — на результате. Иначе глазу не на что опереться.
- **Сцена без финального результата** — зациклена на действии, не видно, чем всё кончилось.
- **Курсор, который промахивается, колеблется, «думает».** Сцена — инструкция, а не запись
  экрана: курсор идёт прямо к цели.
- **Своя анимация появления** у элемента сцены (CSS-переход, keyframes). Для этого есть
  `SceneAppear`; своё движение ещё и не выключится при `prefers-reduced-motion`.
- **Звук, автоплей вне подсказки, сцена на весь экран.** Сцена живёт только в открытой
  подсказке и начинается при её открытии.

## Привязка к стеку полигона

Образец целиком — `assets/examples/dg-name.scene.tsx` (в полигоне Square — `src/prototypes/2026-09-onboarding-motion/scene.tsx`):

```tsx
export const story = defineStory<State>({
  initial: { modal: false, query: '', picked: false, chip: false },
  beats: [
    click('picker', (s) => ({ ...s, modal: true })),
    type('search', 'asanov', (s, query) => ({ ...s, query })),
    click('pick', (s) => ({ ...s, picked: true })),
    click('ok', (s) => ({ ...s, modal: false, chip: true })),
  ],
})

<OnboardingTip title="…" text="…" scene={<OnboardingScene story={story}>{(s) => …}</OnboardingScene>}>
  <Icon name="info" size={16} />
</OnboardingTip>
```

Внутри функции сцены: `ScenePlane` — белая плоскость, `SceneTarget id="…"` — цель шага,
`SceneAppear show={…} kind="item|result"` — то, что появляется и уходит, `SceneWindow` —
окно в границах холста (обычный `Modal` выносится порталом на весь экран и в сцене не работает).
Поля, которые сцена «печатает», — контролируемые: `value={s.query} onChange={() => {}}`.
