# Такт и движение онбординг-сцены

Это спецификация, по которой фронт-команда повторяет сцену на своей ДС. Длительности
появления — ступени токенов `duration/*`; такт действий — хореография, в Figma его нет.
Источник правды в полигоне — `src/shared/onboarding/motion.ts`; таблица ниже обязана
с ним совпадать.

## Движение — одна пружина

Вся сцена движется одной пружиной Apple `.smooth`: период 0,5 с, затухание 1 — без отскока.
Выбрана 07.10.2026 из семи систем (Apple Smooth / Snappy / Bouncy, Material 3, IBM Carbon,
Microsoft Fluent 2 и прежней нашей) на странице сравнения в полигоне — «Онбординг: варианты
анимации». Так устроены системы Apple: одно семейство движения на всё, роли отличаются
длительностью, а не формой.

| Роль | Где | Форма |
|---|---|---|
| `enter` — появление | строка, чип, итог, окно, затемнение, значки у курсора | пружина `.smooth` |
| `exit` — уход | уход строк и окна, затухание сцены перед повтором | та же пружина |
| `move` — путь по экрану | курсор, сдвиг группы, переезд строк, прокрутка, ширина, отдаление | та же пружина |

Форма пружины растянута под длительность — поэтому одна запись годится для любой
длительности. В CSS это `linear()` по 40 точкам кривой `s(p) / s(1)`, где
`s(p) = 1 − e^(−kp)·(1 + kp)`, `k = 2π`, `p` — доля времени; в коде из JS — та же формула.

Деление на `s(1)` обязательно. За отведённое время пружина проходит 98,6 % пути, и без
нормировки оставшиеся 1,4 % добирались последней точкой — 1,6 % пути за последние 2,5 %
времени, видимый скачок в последнем кадре (исправлено в 2.0.1). С нормировкой последний
шаг — 0,2 % пути, такой же плавный, как весь хвост торможения; середина пути почти не
сдвинулась (82 → 83 %). Повторяя на своём стеке, нормируйте так же. `linear` (равномерно) не используется нигде, кроме печати: там каждый
символ появляется мгновенно.

## Такт действия

| Шаг сценария | Из чего состоит | Итого |
|---|---|---|
| вступление (авто) | подсказка появилась (`duration/fast`) + глаз сел | 600 мс |
| `click` | путь курсора 600 → наведение 200 → нажатие 100 → ответ 450 | 1350 мс |
| `rightClick` | путь 600 → мышь у курсора 300 → нажатие 100 → мышь уходит 300 → ответ 450 | 1750 мс |
| `clickWith(key)` | путь 600 → клавиша у курсора 800 → нажатие 100 → ответ 450 | 1950 мс |
| `doubleClick` | путь 600 → наведение 200 → нажатие 100 → пауза 120 → нажатие 100 → ответ 450 | 1570 мс |
| `point` | путь 600 → курсор стоит над целью 800; ответ (если есть) — через 250 | 1400 мс |
| `type` | путь 600 → наведение 200 → нажатие 100 (клик в поле) → фокус 150 → 100 на символ → список успел 400 | 1450 + 100·n мс |
| `type(…, { focused: true })` | поле уже в фокусе (автофокус в открывшемся окне): без клика | 550 + 100·n мс |
| `key(keys)` | клавиши у курсора 800 → первая нажата, каждая следующая через 200, прежние зажаты → 100 → ответ 450 | 1350 + 200·(n − 1) мс |
| `drag(from, to)` | путь 600 → наведение 200 → захват 100 → путь с грузом 800 → над местом сброса 200 → ответ 450 | 2350 мс |
| `resize(handle, to)` | как `drag`, но без копии у курсора; размер едет с курсором | 2350 мс |
| `scroll(target)` | путь 600 → мышь с колёсиком 300 → прокрутка 600 → 450 | 1950 мс |
| `react` | ответ интерфейса без курсора (`duration/moderate`) | 400 мс |
| `wait` | система работает 1000 → ответ 400 | 1400 мс |
| финальный кадр (авто) | результат на экране | 1800 мс |
| повтор (авто) | затухание 300 → сброс → проявление 300 → пауза 400 | 1000 мс |

Состояние меняется в момент **отпускания**, а не нажатия: так на экране видно pressed,
и только потом — ответ. Исключения: `rightClick` — ответ после того, как мышь у курсора
ушла (меню и мышь в одном кадре спорили за взгляд); `resize` — размер начинает меняться
в момент захвата и едет вместе с курсором.

Путь курсора всегда 600 мс, независимо от расстояния: в холсте 400×267 разница в длине
пути не больше трёх раз, и одинаковая длительность читается ровнее, чем «честная».
`wait` — секунда: порог NN/g, до которого ожидание не рвёт ход мысли.

## Появление и уход внутри сцены

| Что | Длительность | Движение |
|---|---|---|
| строка, чип, сообщение — появление | `duration/slow` | прозрачность 0 → 1, сдвиг 4 px сверху |
| строка — уход | `duration/standard`, затем схлопывание 250 мс | гаснет, потом сжимается по высоте — соседи подъезжают, а не прыгают |
| окно — появление | `duration/slow` | вырастает из точки нажатия: масштаб 0,3 → 1, прозрачность 0 → 1; затемнение проявляется за то же время |
| окно — уход | `duration/standard` | обратное открытию: сжимается в ту же точку и гаснет, затемнение тает вместе с ним. Точка запоминается при открытии — крестик её не сдвигает |
| подсветка результата | 1200 мс после появления | заливка `colors/surface/accent/secondaryPressed` в режиме multiply гаснет до нуля |
| смена значения на месте (статус, число) | `duration/slow` | прежнее уезжает вверх и гаснет, новое приходит снизу, блок вырастает с 0,6 |
| переезд строк (сортировка) | `duration/moderate` | каждая строка едет со старого места на новое |
| заполнение (линия шага, прогресс) | `duration/moderate` | акцентная полоса растёт слева направо |
| подрастание при смене состояния | такт ответа (450 мс) | элемент подрастает до 1,12 и садится |
| боковая панель | `duration/standard`, уход `duration/standard` | въезжает справа шириной в половину холста и сдвигает экран влево за край, не сжимая его |
| смена экрана | `duration/slow`, уход `duration/standard` | новый въезжает справа на 24 px, прежний уходит влево |
| отдаление сцены | `duration/moderate` | содержимое выше холста (календарь) сцена показывает, уменьшаясь, пока оно не войдёт целиком |
| нажатие курсора | `duration/instant` | курсор сжат до 0,85, цель в `pressed` |
| круг при нажатии | `duration/moderate` от начала нажатия | плотный круг цвета курсора расходится от его размера до ×2, непрозрачность 0,35 → 0; центр — точка нажатия |
| отклик строки | такт ответа (450 мс) | строка, в которой нажали цель, подрастает до 1,02 и возвращается |
| подсветка строки | `duration/fast`, как у `Table` | строка под курсором — `colors/surface/neutral/tertiary`, в момент нажатия — `tertiaryPressed`; у отмеченной строки постоянного фона нет. У переключателя — без серой строки: у него своё наведение |

Круг нажатия и отклик строки — часть любого нажатия, включать их не нужно и выключить нельзя.
При первом показе сцены и при сбросе перед повтором элементы встают без анимации.

## Правила поведения

- **Наведение идёт за курсором.** Всё, над чем курсор проезжает, получает hovered, как
  у настоящей мыши: строки списка подсвечиваются, пока курсор спускается к нужной.
- **В поле — каретка.** Клик по полю ввода ставит в нём фокус до следующего нажатия;
  у поля в фокусе мигает каретка 2 px в конце текста (цикл 1060 мс, после каждого символа
  мигание начинается заново). Курсор нажимает у начала текста, а не в середину поля, —
  каретка появляется у острия.
- **Точка прицела.** У цели может быть своя часть, куда нажимают (сам переключатель,
  кружок радиокнопки, крестик окна), — состояние наведения при этом стоит на цели целиком.
- **Значки у курсора.** Правая кнопка — мышь 26×38 px, правая половина мигает акцентом,
  в момент клика нажимается и пускает волну; клавиша — 40 px высотой, у Shift контурная
  стрелка ⇧; несколько клавиш (`Ctrl+V`) — рядом, нажимаются по очереди; прокрутка — мышь
  с бегущим колёсиком; удержание края — курсор становится двусторонней стрелкой ширины.
- **Значок в границах холста.** У края холста значок у курсора прижимается внутрь,
  поле от края — 12 px (`SCENE.cueInset`); за край он не выходит.
- **Сцена без курсора.** Нет ни одного пути курсора (только клавиши, печать в открытом поле,
  ответы системы) — курсора нет вовсе. Клавиши стоят сами по себе в свободном месте холста:
  перебор позиций с шагом 2 px, выигрывает та, где они не перекрывают текст, поля и плоскости
  с заливкой или рамкой (сначала с запасом 12 px, потом 6, потом вплотную), из равных —
  ближайшая к центру. Место выбирается при появлении клавиш и не меняется; вырастают они
  из своего центра.
- **Перенос.** У курсора копия источника с тенью и наклоном −2°, источник бледнеет до 0,35,
  место сброса подсвечивается наведением.
- **Центр по итоговому кадру.** Сцена с малым содержимым стоит по центру по вертикали,
  разложенная под финальный кадр: кнопка с начала чуть выше середины, ответ ложится под неё,
  ничего не едет. Не включается, если высота меняется туда и обратно (поле с текстом ошибки).
- **Накладки поверх.** Меню, подсказка, окно лежат над содержимым, а не внутри строки:
  строка при отклике становится своим слоем и закрыла бы накладку.

## Потолки

| | Значение | Если больше |
|---|---|---|
| цикл целиком (вступление → финальный кадр → затухание → пауза перед повтором) | ориентир 8 с, край 9 с | до 9 с движок предупреждает и играет; дольше — не играет: две фичи в одной сцене, разделить |
| действий пользователя (все шаги, кроме `react` и `wait`) | 5 | то же |
| символов в одном `type` | 12 | сцена про печать, а не про фичу — сократить запрос |

Цикл меряется целиком, потому что столько человек ждёт, пока сцена начнётся снова.
Четыре клика дают 8,8 с — это допустимо, пять кликов уже за краем (решение 05.10.2026).

## Геометрия

- Холст 400×267 px в натуральном размере интерфейса, показ в масштабе 0,9 → сцена 360×240.
  До версии 1.2.0 было 480×320 в масштабе 0,75: `body/m` выходил на экране 10,5 px и читался
  с трудом, теперь — 12,6 px.
- Окно в сцене не шире и не выше холста за вычетом полей `paddings/07` с каждой стороны:
  у `Modal` ширина фиксированная (`extraSmall` — 400 px, ровно ширина холста), а его
  собственный потолок считается от вьюпорта, не от холста.
- Подсказка шириной 360: сцена сверху, под ней поле `paddings/07`, заголовок `headline/h5` (16 px, жирный)
  цветом `colors/text/neutral/primary`, зазор `gap/02`, текст `body/m` цветом
  `colors/text/neutral/secondary`. Фон `colors/surface/onColor/neutral/primary`, тень как у `Modal`.
- Белая плоскость `colors/surface/onColor/neutral/primary` занимает холст целиком, без рамки
  вокруг; её поле — `paddings/08`. Серый фон вокруг плоскости читался толстой рамкой и снят
  01.10.2026.
- Курсор — стрелка мыши 14×21 px холста (на экране ≈ 12,6×19, как настоящий курсор) цветом `colors/icon/neutral/primary` с белой обводкой
  1,5 px (`colors/surface/onColor/neutral/primary`); остриё — точка нажатия. Контур стрелки:
  (0, 0), (0, 17,85), (4,62, 13,65), (8,12, 21), (10,5, 19,32), (7, 12,6), (14, 12,6). До версии 1.2.0
  был кружок 20 px — на десктопе он читался как касание пальцем.
- Круг нажатия — прежний: 20 px цветом `colors/icon/neutral/tertiaryHovered`, центр — остриё стрелки.
- Курсор стартует в точке (333, 217) холста — справа внизу, вне целей.
- Открытие по наведению — через 250 мс, уход сразу (общее правило ДС для всего, что
  раскрывается по наведению). Цикл начинается с нуля при каждом открытии.

## Привязка к стеку полигона

- Все числа этой страницы — `src/shared/onboarding/motion.ts` (`SPRING`, `BEAT`, `APPEAR`,
  `WINDOW`, `ZOOM`, `FEEDBACK`, `LIMITS`, `SCENE`). В CSS они приходят переменными `--onb-*`, своих чисел в
  `onboarding.css` нет.
- Токены длительности: `--duration-instant|fast|standard|moderate|slow`.
